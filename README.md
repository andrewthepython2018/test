# Конвертер валют: бесплатная публикация через Stlite и GitHub Pages

`app.py` — ваш Python-код без изменений. `index.html` запускает его в браузере через Stlite 1.12.0. Сервер Python и Docker не нужны. Графика в присланном коде нет; этот комплект публикует конвертер.

## Публикация

1. Создайте публичный репозиторий на GitHub, например `currency-converter`. Можно использовать существующий публичный репозиторий.
2. Через **Add file → Upload files** загрузите `index.html` и `app.py` прямо в корень репозитория, затем сохраните коммит. Загрузите сами файлы, а не ZIP и не содержащую их папку. README можно загрузить по желанию.
3. Откройте **Settings → Pages**.
4. В **Build and deployment → Source** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**. Если основная ветка называется иначе, выберите её.
6. Дождитесь завершения публикации. GitHub покажет адрес вида `https://ВАШ-ЛОГИН.github.io/currency-converter/`.
7. Откройте ссылку, дождитесь загрузки Python, выберите валюту и проверьте расчёт. Отдельно проверьте сайт из сети ученика.

GitHub Pages бесплатен для публичных репозиториев на GitHub Free. Карта не нужна.

## Обновление

Редактируйте `app.py` на GitHub и сохраняйте коммит. Pages опубликует изменения автоматически; после завершения публикации обновите страницу сайта. HTML менять не нужно, пока не добавляете другие файлы или зависимости.

## Локальная проверка

Двойной щелчок по HTML не подходит: браузер должен загружать `app.py` через HTTP. Откройте терминал в папке с файлами и выполните:

```text
python -m http.server 8000 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:8000/`. Остановить сервер — Ctrl+C.

## Что нужно знать

- Первый запуск загружает Python и библиотеки; он тяжелее обычной веб-страницы. Последующие загрузки могут быть быстрее благодаря кешу браузера.
- Курсы запрашиваются из браузера посетителя. Источник API, GitHub Pages, CDN Stlite и ресурсы Pyodide должны быть доступны из его сети. Проверка на другом компьютере не гарантирует доступность у конкретного провайдера в РФ.
- Источник разрешает браузерные запросы (при подготовке проверен заголовок `Access-Control-Allow-Origin: *`).
- Кеш курсов `ttl=3600` сохранён. Это кеш внутри браузерного выполнения приложения, а не общий серверный кеш для всех посетителей.
- Не помещайте секретные API-ключи в этот проект: браузерный код доступен посетителям. Для используемого API ключ не нужен.
- Для локального запуска обычного Streamlit вместо Stlite можно установить `streamlit requests` и выполнить `streamlit run app.py`.
