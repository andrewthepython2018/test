# Правка загрузки курсов для Stlite

Замените app.py и index.html в том же репозитории, где опубликован конвертер.
Дождитесь завершения публикации Pages и обновите сайт на телефоне.

Что изменилось:
- requests.get() заменён на асинхронный pyodide.http.pyfetch().
- Добавлен тайм-аут 20 секунд на загрузку ответа и JSON.
- Перехватываются сетевые ошибки Python и JsException из браузера.
- При ошибке показываются сообщение, ссылка на источник и кнопка повтора.
- Успешный ответ хранится в st.session_state в течение часа.
- requirements в HTML теперь пуст: requests больше не нужен.

app.py рассчитан на Stlite/Pyodide. Здесь есть await на верхнем уровне;
обычный запуск python app.py или streamlit run app.py не поддерживается.
Для обычного Streamlit сохраняйте исходную версию проекта отдельно.

Это замена транспорта и обработка ошибки, а не подтверждённое устранение
причины сбоя на конкретном телефоне. Если сеть или браузер блокирует API,
pyfetch тоже не сможет получить данные. Проверять нужно на устройстве,
где возникала ошибка.

Диагностика до и после замены:
1. Откройте сайт в обычном Chrome или другом актуальном браузере,
   отдельно от встроенного окна приложения.
2. На том же устройстве откройте https://www.cbr-xml-daily.ru/daily_json.js
   Если не открывается, проверьте другую сеть.
3. Если JSON открывается, но приложение нет, это ещё не исключает CORS:
   прямая навигация и запрос со страницы имеют разные ограничения.
4. Сравните работу через Wi-Fi и мобильный интернет.
